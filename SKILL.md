# Скилл: Антиплагиат — обход ИИ-детекторов

## Назначение

Переработка текста так, чтобы он проходил проверку ИИ-детекторами (Антиплагиат.ВУЗ, GPTZero, ZeroGPT, GigaCheck) и читался как написанный живым человеком. Не меняет смысл — только стиль, ритм, лексику, структуру предложений.

---

## Порядок работы

### Шаг 1. Получить текст

Прими от пользователя текст для переработки. Если текст не передан — запроси.
Уточни при необходимости:

- Стиль (академический, научный, деловой, нейтральный)
- Сохранять ли структуру абзацев
- Есть ли запрещённые к изменению фрагменты (цитаты, термины, названия)

### Шаг 2. Диагностика

Перед переработкой — внутренний анализ текста:

- Найди повторяющиеся конструкции и слова-паразиты
- Выяви «ИИ-паттерны»: одинаковая длина предложений, шаблонные переходы, перечисления с параллельными структурами, начала абзацев с «Таким образом»
- Отметь абзацы с нулевой конкретикой (только общие слова без фактов)

### Шаг 3. Прочитать правила стиля

**ОБЯЗАТЕЛЬНО** прочитай `references/anti_ai_rules.md` ПЕРЕД переработкой.
Это главный файл — он определяет, пройдёт ли результат проверку.

### Шаг 4. Переработка

Применяй правила из `references/anti_ai_rules.md` последовательно к каждому абзацу.
Между абзацами проверяй: не появились ли новые повторы.

### Шаг 5. Финальная проверка

После переработки пройдись по тексту и убедись:

- Ни одна запрещённая фраза не проскочила
- Длина предложений чередуется (короткие / средние / длинные)
- Каждый абзац начинается по-разному
- Нет трёх предложений подряд с одинаковой структурой

## КРАТКАЯ ВЫЖИМКА ПРАВИЛ СТИЛЯ

*(полный свод — в `references/anti_ai_rules.md`)*

### Абсолютно запрещённые фразы — удалить или переформулировать

- «Важно/стоит/следует/необходимо/можно отметить»
- «В современном мире» / «В настоящее время» / «На сегодняшний день»
- «Играет важную/ключевую/значительную роль»
- «Рассмотрим подробнее» / «Перейдём к анализу» / «Далее будет рассмотрено»
- «В заключение стоит сказать» / «Подводя итог»
- «Таким образом, можно сделать вывод»
- «Вышеупомянутый» / «Нижеследующий»

### Строго ограниченные — максимум 2-3 на весь текст

- «является» → заменяй на тире
- «данный» → заменяй на «этот»
- «таким образом» → макс. 2 раза
- «обеспечивает» / «позволяет» → макс. 2-3 раза каждое
- «во-первых / во-вторых / в-третьих» → макс. 1 серия на весь текст

### Обязательные приёмы

1. **Ритм предложений** — чередуй короткие (5-8 слов), средние (15-20 слов),
   длинные (25-35 слов). Никогда 3+ подряд одинаковой длины.

2. **Разные начала абзацев** — чередуй: факт, обстоятельство, результат,
   причина, деепричастный оборот, противопоставление, числительное.

3. **Конкретика** — если в тексте есть данные (числа, названия, версии) —
   сохраняй и выделяй их. Если абзац пустой — добавляй уточняющий вопрос-заглушку.

4. **Признаки человеческого мышления** — там, где уместно, показывай выбор:
   «Изначально рассматривался X, но из-за Y выбран Z».

5. **Неравномерность** — живой текст неравномерен. Один абзац — длиннее,
   следующий — короче. Одно предложение — сложное, следующее — из пяти слов.

6. **После переформулировки не добавляй объяснений** — просто дай готовый текст.

## Что НЕ делать

- Не менять смысл, факты, цифры, термины
- Не удалять цитаты и ссылки
- Не добавлять информацию, которой не было в исходнике
- Не делать текст разговорным, если стиль — академический
- Не объяснять каждое изменение (если пользователь не просил)

## Когда данных не хватает

Если абзац содержит только общие слова и никакой конкретики —
вставляй заглушку вместо додумывания:
